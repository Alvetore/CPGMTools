# Броня, инициатива, звук и ширма — 25.10.2026

## Исправления

- В общем резолвере половина оставшейся SP округляется вверх: SP 11 → 6. Изменение действует для быстрого ИРЛ-урона, резолвера атаки и профилей с `armorPenetration: half`. Brawling использует полную SP. Урон, равный эффективной SP, не пробивает и не стирает броню.
- Ручная правка инициативы раньше меняла число без пересортировки. Перебросы сбрасывали индекс хода на 0; некоторые способы добавления участников просто дописывали их в конец списка.
- `orderCombatants` теперь отвечает за порядок по убыванию инициативы и сохранение текущего участника по ID в активном бою. Используется при ручных правках, перебросах, добавлении партии/NPC/подкреплений, быстром добавлении, начале боя и загрузке сохранения. Новые участники активного боя получают бросок инициативы. Раунд при пересортировке не меняется.
- При обычных правках и загрузке равные значения сохраняют установленный порядок, без случайных перебросов при каждом вводимом символе. Явный бросок/применение инициативы разрешает ничьи перебросом, сохраняя исходные итоги на карточках.
- Переключатель звука сохраняет оба состояния в браузере (`cpgm_sound_muted`). Если LocalStorage заблокирован, переключатель продолжает работать в текущем сеансе. Это локальная настройка браузера, отдельная от базы персонажей и её резервных копий.
- В ширме скрытая горизонтальная полоса делала дальние разделы неудобными для мыши. На ПК (от 768 CSS px) разделы переносятся на несколько строк; на узком экране остаётся горизонтальная прокрутка с видимой полосой.
