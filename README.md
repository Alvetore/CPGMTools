# 🕶️ Cyberpunk RED — Инструменты ГМа (GM Toolkit)

Полнофункциональный, стилизованный веб-комплекс инструментов для Мастера (Game Master / Referee) по настольной ролевой игре **Cyberpunk RED**. Работает 100% в браузере (Pure Client-Side SPA) и оптимизирован для бесплатного хостинга на **GitHub Pages**.

Полностью совместим с интерактивным листом персонажа [CyberpunkCharSheetG](https://github.com/Alvetore/CyberpunkCharSheet) и базой данных [Data Pool](https://alec-leon.github.io/data-pool/).

---

## 🌟 Ключевые возможности

### 1. ⚔️ Боевой трекер Cyberpunk RED (Combat Engine)
- **Инициатива:** бросок `1d10 + REF` с авто-разрешением ничьих по показателю `REF`.
- **Пороги ранений и авто-штрафы:**
  - *Норма* (> 50% HP);
  - *Тяжело ранен (Seriously Wounded)* (≤ 50% HP) ➔ автоматический бейдж и штраф **-2 ко всем действиям**;
  - *Смертельно ранен (Mortally Wounded)* (0 HP) ➔ штраф **-4 ко всем действиям** + трекер раундов смерти (+1 штраф каждый раунд).
  - **Кнопка «Спасбросок смерти»:** бросок `1d10 + штраф раундов < ТЕЛО (BODY)`. Автоматическое определение натуральной 10 (мгновенная смерть).
- **Раздельная броня Голова / Тело:**
  - Отдельный учет Head SP и Body SP.
  - Кнопка истирания брони (**-1 SP** при обычном пробитии, **-2 SP** для бронебойных AP патронов).
  - Быстрое восстановление брони (Repair).
- **Интерактивный резолвер атак и урона:**
  - Выбор атакующего и цели в бою.
  - Выбор дистанции (0-6м, 7-12м, 13-25м, 26-50м, 51-100м) ➔ автоматический расчет сложности (DV) по официальной таблице **Range DV**.
  - Проверка атаки `1d10 + База стрелка` с взрывающимися десятками и критическими провалами.
  - Прицельный выстрел в голову (-8 к проверке, **удвоение пробивающего урона $\times 2$**).
  - Атаки ближнего боя (игнорируют 50% SP брони цели).
  - Авто-определение двух и более шестерок ($6, 6$): **+5 бонусного урона** и автоматический бросок критической травмы по таблице 2d6!
- **Горячая клавиша:** переход к следующему ходу по нажатию **`Space` (Пробел)**.
- **Подробный журнал боевых событий (Combat Log).**

### 2. 👥 Постоянная партия игроков & Прямой импорт из `CyberpunkCharSheetG`
- **Импорт в 1 клик:** мастер просто загружает `.json` файл, экспортированный игроком из чарника `CyberpunkCharSheetG`.
- Автоматически считываются:
  - Имя, уличная кличка (Handle), роль;
  - Все характеристики: `REF`, `DEX`, `MOVE`, `BODY`, `EMP`, `LUCK`;
  - Здоровье (HP) и пассивное восприятие (`INT + Perception`);
  - Броня головы и тела (Head SP / Body SP);
  - Список активного оружия с уроном и патронами.
- **«Отправить партию в бой»:** добавление всех игроков в активный боевой трекер в один клик.
- **«Отдых и исцеление»:** 1 день отдыха восстанавливает здоровье на величину характеристики `BODY`, восполняет очки Удачи и чинит броню.

### 3. 🧬 Бестиарий и генератор банд Найт-Сити
- **Официальные шаблоны врагов из книги правил Cyberpunk RED:**
  - *Mooks (Шестёрки / Пушечное мясо):* Телохранитель (Bodyguard), Дорожный бандит (Road Ganger), Офицер службы безопасности (Security Guard), Пироман банды Мальстрём (Pyro Booster).
  - *Lieutenants (Лейтенанты):* Ветеран-Соло (Solo Veteran).
  - *Bosses (Боссы):* Киберпсихопат (Cyberpsycho).
  - *Дроны:* Боевой дрон-паук (Combat Spider Drone).
- **Генератор уличных бандитов за 1 клик:**
  - Выбор банды: *Мальстрём (Maelstrom)*, *Тигриные Когти (Tyger Claws)*, *Шельмы (The Mox)*, *6-я Улица (6th Street)*, *Животные (Animals)*, *Инквизиторы (Inquisitors)*.
  - Выбор ранга (Mook, Lieutenant, Boss).
  - Генерирует имя, кличку, броню, оружие, киберимпланты, тактику и случайный лут в карманах.
- Быстрое добавление групп противников (например, *«Бустер Мальстрём» × 4*).

### 4. 🌐 Интерактивная Архитектура Сети (NET Architecture Runner)
- Процедурный генератор и трекер многоэтажных сетей:
  - Сложности: *Basic* (3–4 этажа), *Standard* (5–6 этажей), *Advanced* (7–8 этажей), *Military* (8–10 этажей).
  - Типы узлов:
    - 🔒 **Пароли / Межсетевые экраны (Password)** с DV взлома;
    - 🎛️ **Узлы управления (Control Nodes):** камеры наблюдения, турели, лифты, вентиляция;
    - 📁 **Файлы данных (Files)** с секретными чертежами и документами;
    - 🐉 **Чёрный Лёд (Black ICE):** *Адская гончая (Hellhound)*, *Аспид (Asp)*, *Скорпион (Scorpion)*, *Ворон (Raven)*, *Скунс (Skunk)*, *Кракен (Kraken)*, *Гигант (Giant)*, *Дракон (Dragon)*.
    - 😈 **Охранные Демоны:** *Бес (Imp)*, *Ифрит (Efreet)*, *Балрог (Balron)*.
- **HUD Нетраннера:**
  - Трекер действий Сети (Net Actions) в зависимости от ранга Интерфейса (2–5 действий).
  - Отметка активного этажа нахождения нетраннера.
  - Бой с Чёрным Льдом: учет прочности REZ, статуса Derezzed и атаки.

### 5. 🎲 Ширма Мастера & Генераторы Найт-Сити
- **Официальная таблица дистанций (Range DV Table):**
  - Интерактивная сетка для Пистолетов, ПП, Дробовиков (жаканы/картечь), Штурмовых и Снайперских винтовок, Луков и Очередей (Autofire).
- **Таблица сложностей проверок навыков:**
  - От 9 (Simple) до 29 (Incredible) с примерами.
- **Таблица критических травм 2d6:**
  - Все травмы головы и тела со сложностями полевой помощи (First Aid / Paramedic) и хирургии (Surgery).
- **Генератор заказов (Gigs & Screamsheets):**
  - Заказчик, задача, локация, сюжетный твист и гонорар в евродолларах (eb).
- **Погода Найт-Сити:**
  - Кислотный дождь, токсичный смог, песчаная буря Пустошей, кровавый закат и уличные сценки.
- **Обыск карманов (1d100 Pocket Junk):**
  - Кредчипы, уличные наркотики (Black Lace, Synthcoke), пиратские брейндансы, патроны, ключи от мотелей.
- **Встроенный дайсроллер Cyberpunk RED:**
  - Броски 1d10 со взрывом 10 и вычитанием 1, Nd6 на урон, спасброски смерти.

## 🚀 Быстрый старт и запуск

### Локальный запуск
1. Убедитесь, что установлен [Node.js](https://nodejs.org/) (версии 18+).
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
4. Откройте адрес `http://localhost:5173` в браузере.

### Сборка
```bash
npm run build
```
Готовые статические файлы для любого веб-сервера находятся в папке `dist/`.

## 🌐 Публикация на GitHub Pages

В репозитории уже настроен GitHub Actions workflow (`.github/workflows/deploy.yml`).

1. Создайте репозиторий на GitHub (например, `CPGMTools`).
2. Запушьте код:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Cyberpunk RED GM Tools"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_АККАУНТ>/CPGMTools.git
   git push -u origin main
   ```
3. В настройках репозитория на GitHub: **Settings ➔ Pages ➔ Source ➔ GitHub Actions**.
4. Сайт будет опубликован и доступен по адресу `https://<ВАШ_АККАУНТ>.github.io/CPGMTools/`.
