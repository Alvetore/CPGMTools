# 🕶️ Cyberpunk RED — Инструменты ГМа (GM Toolkit)

Полнофункциональный, стилизованный веб-комплекс инструментов для Мастера (Game Master / Referee) по настольной ролевой игре **Cyberpunk RED**. Работает 100% в браузере (Pure Client-Side SPA) и оптимизирован для бесплатного хостинга на **GitHub Pages**.

Поддерживает JSON-импорт из интерактивного листа персонажа [Cyberpunk RED CharSheet](https://alvetore.github.io/CyberpunkREDCharSheet/). Справочные данные требуют сверки с актуальными изданиями RTG. Поддержка DLC и пределы автоматизации описаны в [результатах исправлений](audit/RELEASE-2026-10-23.md) и [реестре DLC](audit/dlc-coverage.json).

Экспорт одного персонажа и «Экспорт всех» чарника можно загрузить через «Партия игроков → Импорт (.JSON)» или верхнюю кнопку импорта. Связи кибероружия, слоты установки, инвентарь имплантов, профили и магазины сохраняются в исходном листе и бэкапе GM Tools. Используется профиль, выбранный в чарнике. Спецэффекты без обычного урона разрешаются вручную. При включённых автоэффектах киберимплантов сверьте BODY, HP, SP и инициативу: эти эффекты GM Tools пока не пересчитывает; карточка показывает предупреждение. [Проверка совместимости от 25.10.2026](audit/CHARSHEET-COMPAT-2026-10-25.md).

Обновление чарника с рюкзаком также поддержано: оружие с `isEquipped:false` хранится вместе с остальным имуществом, но не доступно для атаки. Запасная броня, транспорт, новые отношения биографии и сведения каталогов сохраняются в `sourceCharSheet` и бэкапах. Гранаты разрешаются вручную по описанию. [Свежая проверка синхронизации](audit/CHARSHEET-SYNC-2026-10-25.md) включает повторяемый прогон по исходникам чарника.

## 🌟 Ключевые возможности

### 1. ⚔️ Боевой трекер Cyberpunk RED (Combat Engine)
- **Инициатива:** бросок `1d10 + REF` с критическими 1/10 и перебросом ничьих.
- **Пороги ранений и авто-штрафы:**
  - *Норма* (от округлённой вверх половины HP);
  - *Тяжело ранен (Seriously Wounded)* (ниже округлённой вверх половины HP) ➔ автоматический бейдж и штраф **-2 ко всем действиям**;
  - *Смертельно ранен (Mortally Wounded)* (0 HP) ➔ штраф **-4 ко всем действиям** + трекер выполненных спасбросков (+1 после каждого броска).
  - **Кнопка «Спасбросок смерти»:** бросок `1d10 + штраф раундов < ТЕЛО (BODY)`. Автоматическое определение натуральной 10 (мгновенная смерть).
- **Раздельная броня Голова / Тело:**
  - Отдельный учет Head SP и Body SP.
  - Кнопка истирания брони (**-1 SP** при обычном пробитии, **-2 SP** для бронебойных AP патронов).
  - Быстрое восстановление брони (Repair).
- **Интерактивный резолвер атак и урона:**
  - Выбор атакующего и цели в бою.
  - Выбор дистанции (восемь диапазонов от 0–6 до 401–800 м) ➔ автоматический расчет сложности (DV) по официальной таблице **Range DV**.
  - Проверка атаки `1d10 + База стрелка` с взрывающимися десятками и критическими провалами.
  - Прицельный выстрел в голову (-8 к проверке, **удвоение пробивающего урона $\times 2$**).
  - Оружие ближнего боя и Martial Arts используют половину SP с округлением оставшейся защиты вверх (SP 11 → 6); Brawling использует полную SP. Уклонение вводится как готовый итог или бросается отдельно.
  - Авто-определение двух и более шестерок ($6, 6$): **+5 напрямую в HP, отдельно от брони и множителя головы,** и автоматический бросок критической травмы по таблице 2d6!
- **Горячая клавиша:** переход к следующему ходу по нажатию **`Space` (Пробел)**.
- **Подробный журнал боевых событий (Combat Log).**

### 2. 🚗 Трекер погонь Cyberpunk RED (DLC Hot Pursuit)
*Реализация официальных правил автомобильных погонь из сборника Interface Kr45n1y:*
- **Интерактивная сетка погони (Chase Grid):** относительные координаты машин без ограничения длины сетки. При отрыве более 8 клеток от всех преследователей — цель скрывается в городских джунглях (Побег).
- **Проверка позиционирования в конце раунда:**
  - Автоматический расчет СЛ в зависимости от боевой скорости: 60 СКО (СЛ 13), 40 СКО (СЛ 15), 20 СКО (СЛ 17), 15 СКО (СЛ 21), 10 СКО (СЛ 24), 8 СКО (СЛ 29).
  - **Критическое повреждение ПСП (SDP < 50%):** автоматическое снижение эффективной боевой скорости на одну категорию (при падении ниже 8 СКО — машина теряет управление и разбивается!).
- **Особые манёвры Hot Pursuit в 1 клик:**
  - ⚡ **Ускорение закисью азота (NOS) [СЛ 13]:** мгновенный рывок на +1 клетку вперед.
  - 🚓 **Полицейский манёвр PIT [СЛ 15]:** таран бок о бок, накладывающий штраф скорости на цель в конце раунда.
  - 🏎️ **Выход вперёд / Опережение [СЛ 17]:** обгон соперника с выходом на клетку вперед.
  - 🎯 **Подтянуться ближе [СЛ 13]:** сокращение дистанции до ближнего края для абордажа и ближнего боя.
  - 💥 **Таран [СЛ 17]:** лобовое столкновение на полной скорости.

### 3. 👥 Постоянная партия игроков & Прямой импорт из [Cyberpunk RED CharSheet](https://alvetore.github.io/CyberpunkREDCharSheet/)
- **Импорт в 1 клик:** мастер просто загружает `.json` файл, экспортированный игроком из чарника.
- Автоматически считываются:
  - Имя, уличная кличка (Handle), роль;
  - Все характеристики: `REF`, `DEX`, `MOVE`, `BODY`, `EMP`, `LUCK`;
  - Здоровье (HP) и пассивное восприятие (`INT + Perception`);
  - Броня головы и тела (Head SP / Body SP);
  - Список активного оружия с уроном и патронами.
- **«Отправить партию в бой»:** добавление всех игроков в активный боевой трекер в один клик.
- **«Отдых и исцеление»:** 1 день естественного отдыха стабилизированного персонажа восстанавливает здоровье на величину характеристики `BODY` (по правилам CPR стр. 222; починка брони производится отдельно навыком Базовая Техника).

### 5. 🌐 Интерактивная Архитектура Сети (NET Architecture Runner)
- Процедурный генератор и трекер многоэтажных сетей:
  - Сложности: *Basic* (3–4 этажа), *Standard* (5–6 этажей), *Advanced* (7–8 этажей), *Military* (8–10 этажей).
  - Типы узлов:
    - 🔒 **Пароли / Межсетевые экраны (Password)** с DV взлома;
    - 🎛️ **Узлы управления (Control Nodes):** камеры наблюдения, турели, лифты, вентиляция;
    - 📁 **Файлы данных (Files)** с секретными чертежами и документами;
    - 🐉 **Чёрный Лёд (Black ICE):** *Адская гончая (Hellhound)*, *Аспид (Asp)*, *Скорпион (Scorpion)*, *Ворон (Raven)*, *Скунс (Skunk)*, *Кракен (Kraken)*, *Гигант (Giant)*, *Дракон (Dragon)*.
    - 😈 **Охранные Демоны:** *Бес (Imp)*, *Ифрит (Efreet)*, *Балрог (Balron)*.
- **HUD Нетраннера:**
  - Трекер действий Сети (Net Actions) в зависимости от ранга Интерфейса (2–5 действий).
  - Отметка активного этажа нахождения нетраннера.
  - Бой с Чёрным Льдом: учет прочности REZ, статуса Derezzed и атаки.

## 🚀 Быстрый старт и запуск

### Локальный запуск
1. Убедитесь, что установлен [Node.js](https://nodejs.org/) (версии 20.19+ или 22.12+).
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```
4. Откройте адрес `http://localhost:5173` в браузере.

### Сборка проекта
```bash
npm test
npm run build
```
Готовые статические файлы находятся в папке `dist/`.

## 🌐 Публикация на GitHub Pages

В репозитории настроен автоматический деплой через GitHub Actions (`.github/workflows/deploy.yml`).

1. В настройках репозитория: **Settings ➔ Pages**.
2. В блоке **Build and deployment**: выберите **Source ➔ GitHub Actions**.
3. После пуша в ветку `main` сайт автоматически доступен по адресу:
   👉 **[https://alvetore.github.io/CPGMTools/](https://alvetore.github.io/CPGMTools/)**
